# Contribuicao privada

Obtenha autorizacao do titular antes de colaborar ou compartilhar. Contribuir nao concede autorizacao de publicacao nem transfere automaticamente direitos autorais; acerte a permissao necessaria para incorporar a contribuicao.

Crie branch curta, explique objetivo e riscos, inclua testes e abra PR. Use Python 3.10+ e biblioteca padrao no nucleo. Evite dependencias pesadas obrigatorias. Nao inclua segredos, bancos reais, modelos ou executaveis.

Checklist: testes offline, compilacao, CI verde para o commit atual, preservacao de dados, nenhuma rede implicita, sem shell, entrada validada, documentacao em portugues e limites claros. Nao aceitar funcionalidade apenas porque criou uma pasta com nome convincente.
